How payments work on Event World
Students pay directly to your Razorpay account. Event World does not collect or hold any money. You need a Razorpay account to accept payments. Create one free at razorpay.com. You are responsible for managing refunds directly with students. Event World does not process refunds.
₹
Find this in Razorpay Dashboard → Settings → API Keys. Use test key for testing, live key for real payments.
✅ Valid Razorpay Key format
❌ Invalid format. Should start with rzp_test_ or rzp_live_
📋 How to get your Razorpay Key ID:
1. Go to razorpay.com and create a free account
2. Complete KYC verification (required for live payments)
3. Go to Settings → API Keys
4. Generate Test Key for testing or Live Key for real payments
5. Copy the Key ID (NOT the Key Secret) and paste it above
